## 〇、字段与通用规则

### 1. 每条目字段

`id / 名称 / 来源神（tier）/ 系 / 品质 / 镶嵌属性 / 是否可觉醒 / 觉醒主动技（名称+类型+系数+耗神力+冷却）/ 被动`

- **品质**：凡品（白）/ 灵品（绿）/ 宝品（蓝）/ 仙品（金）。品质≠神的 tier，但强相关：**D 神产同名碎片，5 枚凝该神灵品专属格**；凝格池泛来源（无署名）出凡品格；C 神长单出宝品整格，B 神出宝品，A 神出宝~仙品，S 神仅主线仙格。本期品质分布：凡 3 / 灵 9 / 宝 27 / 仙 14。
- **镶嵌属性**：嵌上即得，不觉醒也生效。
- **觉醒**：每枚都可参悟觉醒（除标注「不可」者）；觉醒后获得主动技与被动。
- 主动技类型（与战斗组约定）：

| type | 效果 |
|---|---|
| `nuke` | 一次性重击，系数为攻击力百分比 |
| `nukeStun` | 重击 + 震骇（敌跳过行动，1 回合） |
| `vuln` | 伤害 + 易伤（敌 +50% 承伤，N 回合） |
| `nukeHeal` | 伤害 + 按比例回血 |
| `shield` | 获得生命上限百分比护盾（可带回合数） |
| `heal` | 直接回复生命上限百分比 |
| `burn` | 伤害 + 灼烧（N 回合内每回合受攻击力百分比火伤） |
| `percentStun` | **真实伤害**（按敌最大生命 %，无视防御与神位减伤）+ 震骇 |
| `percentHeal` | **真实伤害**（按敌最大生命 %）+ 自身回血 |
| `control` | 雷控/麻痹：震骇 1 回合并附导电/易伤标记 |
| `cleanse` | 净化自身异常（灼烧/中毒/削弱），可附带回血 |

- 冷却单位为**战斗回合**；每场战斗通常 8~14 回合、3 个关键时刻，冷却 4~5 意味着一场用 2~3 次。
- 主动技伤害吃暴击/易伤；percent 技不吃攻防，只受「真实伤害加成」（幽系共鸣、妖丹之力）影响。

### 2. 属性数值预算（镶嵌属性总和）

| 品质 | HP | ATK | DEF | 可带特殊词条 |
|---|---|---|---|---|
| 凡品 | 8~15 | 2~4 | 0~3 | — |
| 灵品 | 15~28 | 4~6 | 2~5 | 暴击/吸血小词条 |
| 宝品 | 28~48 | 6~11 | 4~9 | 暴击/吸血/减伤 |
| 仙品 | 45~68 | 9~16 | 6~14 | 双特殊词条 |

| **兵 ↔ 法** | 刚猛斗神与控场雷法路数相冲 | 神力上限 **−20%**（侵蚀 40+ 扩大为 −30%） |
| **幽 ↔ 生** | 死气与生机相逆 | 神力上限 **−20%**（同上） |
| **火** | 中性调和 | **不与任何系道争**；但火也不替任何系凑共鸣计数 |

> 设计意图：道争是「全才税」而非「不能玩」——靠香炉设施（MP 上限）与融合格（异途格自带调和标签，见下）可以硬凑混搭流，但要付容量与成本。
