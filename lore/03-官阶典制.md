# 天道打工人 · 官阶典制（知识库分册 03 · v3）

> 本册为地府组织架构与玩家 9 阶晋升的**唯一权威设定源**，服从 `00-世界观总纲.md` 第七节。旧 `js/data.js` 中 RANKS 仅 5 阶且官名混乱（「从七品判官」），以本册为准重制。
> 考据原则：架构依道教幽冥神系（《真灵位业图》《元始上真众仙记》《道门科范大全集》）与民俗《玉历宝钞》《阎王经》通行成说；俗名与道籍有分歧处并列标注。游戏虚构的外包品阶、KPI 功过簿明确为演绎。

## 一、地府组织架构（真实阴司）

### 1. 架构全图（自上而下）

```
后土皇地祇（幽冥本源·大地之母）
└─ 东岳大帝（泰山府君，生死总领，核查人间善恶）
   └─ 酆都大帝（罗酆山，幽冥执行之首，实际CEO）
      ├─ 五方鬼帝（镇五方鬼门，古神遗老）
      ├─ 十殿阎罗（十殿轮审，从生到死到投胎的流水线）
      │   └─ 四大判官（赏善/罚恶/察查/阴律，阎罗的秘书省）
      │       └─ 十大阴帅（外勤武力与拘拿系统）
      │           ├─ 城隍（阳间各城驻阴办事处）
      │           │   └─ 土地（街巷井泉末梢，最小编制）
      │           └─ 各地山神、水神、灶君、门神等小神（协管，非阴司直辖）
      └─ 枉死城、十八层地狱、忘川、奈何桥、孟婆汤（羁押与轮回设施）
```

## 二、编制对照表（真实阴司 × 玩家外包体系）

> 核心戏剧设计：玩家不是阴司的人，是**外包人力**，所以没有真实官身，只有「比照品阶」。这张对照表决定 NPC 对玩家的称呼、门禁与白眼。

| 玩家阶 | 玩家官名（外包/合同体系） | 比照真实阴司职级 | 能进的门 | 典型 NPC 态度 |
|---|---|---|---|---|
| 0 | 九品阴神（外包） | 无籍鬼差以下（临时工都不如，无腰牌，只有一纸「阴阳两界劳务契」） | 自己的破神衙、城隍庙前廊、枉死城外城 | 鬼差：「哎那谁」；土地公：平等相待 |
| 1 | 从八品·阴阳差役 | 比照最低等**鬼差/阴兵什长** | 枉死城内城、十殿文书房抄录处 | 鬼差开始叫「兄弟」 |
| 2 | 八品·两界巡按 | 比照**城隍麾下经制差役/巡按行走** | 各城城隍档案室、野庙勘验 | 城隍让座，土地作揖 |
| 3 | 从七品·主簿 | 比照**判官府主簿**（崔珏的幕僚序列） | 判官四司档房、生死簿外库 | 小鬼称「主簿爷」，阴帅点头 |
| 4 | 七品·判官 | 比照**判官行走/协判**（非正式判官，但可坐堂录供） | 十殿偏堂、可代行初审 | 十殿小吏垂手，厉鬼见了要跪 |
| 5 | 从六品·推官 | 比照**一殿推官**（专司复核疑难案） | 十殿正堂侧席、可直接调阅卷宗 | 阎罗王们开始记得你的名字 |
| 6 | 六品·刑曹 | 比照**阴帅府刑曹参军** | 阴帅军营、枉死城军防 | 鬼王级平礼 |
| 7 | 从五品·酆都判官中丞 | 比照**酆都御史中丞**（监察系统，可参判官） | 酆都台、可稽查四司 | 四判官以同僚礼待 |
| 8 | 五品·阴司少卿 | 比照**地府少卿**（十殿与酆都之间的通译高官） | 除酆都内殿外皆可通行 | 二线 NPC 的天花板，阎罗赐座 |

配套规则：
- 玩家的「官身」全称永远带后缀，合同文本上写作「**从八品阴阳差役（外包·不给编）**」——UI 中括号内容鼠标悬停才可见，黑色幽默点。
- 真实品阶持有者对玩家有**名器压制**：如被正式阎罗/判官当堂呵斥，玩家战斗类增益在该剧情段失效（叙事用，不作常驻机制）。
- 章5 结局分水岭（母本）：入编→从六品转**实授**（去「外包」后缀，结局A）；掀桌→所有品阶注销（结局B）；阴天官→品阶表对其失效，另立法统（结局C）。

字段说明：
- **神明 tier 上限**：高于上限的神明不派单、不见面（或只见其文书不见其人，如章4前的相爷）。
- **神格盘槽位**：可同时镶嵌的整格数；碎片不占槽（存在神龛待凝）。
- **工单架容量**：案几上可同时挂起（跨日保留）的未结工单上限；官遣 forced 单不占容量。
- **阴兵编制**：可招募的鬼差/阴兵/亲兵数量上限，招妖幡设施在本阶上限内再细分。
- **设施总级上限**：神衙全部设施等级数之和的天花板（神龛、案几、香炉、招妖幡、三期香火设施等），防止单阶内花钱碾压数值。

### 2. 各阶解锁详注

#### 阶0 · 九品阴神（外包）
- 入职礼包：值房一间、漏雨屋顶、红灯笼一盏、空白功过簿一本、《阴阳两界劳务契》（三十日一考，条款在背面）。
- 只接得到 E 级小神私活与 D 级神的最零碎杂单（D 神此阶只给香火钱/人情，不给碎片）。
- 设施只能维持初始四级（神龛/案几/香炉/招妖幡各一）。

#### 阶1 · 从八品·阴阳差役（章1末）
- **双条件硬卡**：章1主线「两界文书房试炼」结案 + 第一个考核月 KPI 达标（两条件在 UI 上同时打勾才触发转正剧情）。
- 解锁：D 级神格碎片掉落（3~5 枚凝1格，凝格界面同步开放）；可入枉死城内城。
- 【游戏文本】*转正朱批*：「着即转正，从八品阴阳差役（外包），月例折香若干，不得佩印。」——落款处「外包」二字墨色明显比别的字新。

#### 阶2 · 八品·两界巡按（章2末）
- 条件：章2主线结案 + 功过累计达标（建议累计 ≥220，即前两月成绩中上）。
- 解锁：C 级神官工单池；长单系统；C 级神的**长单可出整格**（首个稳定整格来源，对应母本 tier 表）。
- 野庙空心案后，E/D 级小神对你说话开始吞吞吐吐——你已经能看见他们不想让你看见的东西了。

#### 阶3 · 从七品·主簿（章3末）
- **硬卡：崔珏举荐**。崔珏好感需达「信重（50）」以上并完成其生死簿任务链（查伪笔→夜审空壳判官→收下那半册账）。举荐有政治代价：剧情中崔珏被罚俸半年，这是玩家的第一笔「人情债」。
- 解锁：B 级天君工单池与整格掉落；判官四司档房门禁；阴兵编制 +1（可配第三名阴兵）。
- 若崔珏好感不足，章3 无法晋升，玩家以八品身份多跑一个月「留用察看」工单（缓冲设计，不卡关死）。

#### 阶4 · 七品·判官（章4末）
- 条件：章4主线 + **三场末考**：
  1. 察查考（陆之道主考）——证据链选择，对错决定物证完整度（影响终章舆论）；
  2. 刑名考（钟馗主考）——连续两场实战，限定神格类别（逼玩家理解四类克制）；
  3. 德行考（魏征主考）——无考题，只核功过簿：贪墨/吞噬妖丹次数过多则降等录用。
- 解锁：可坐堂录供（游戏表现为新的事件选项「当堂宣判」，部分工单可免战了结）；A 级神明在此阶末**可初见**（只闻其声/只见神念，不出整格）。

#### 阶5 · 从六品·推官（章5中）
- **主线选择限定**（母本规定）：
  - 入局线：天曹叙功，实授从六品（结局A 的前半步）；
  - 掀桌线：品阶在受职现场被玩家自己辞去（朱批墨迹未干即焚契）；
  - 阴天官线：不接、不辞，以「有实无名」之身行推官事，NPC 称呼变为意味深长的「您」。
- 数值上若授阶：解锁 A 级整格与稀有神通；神格盘 6 槽是终章战的关键容量。
- 阶6~8 为二期长线，数值解锁已列在总表，剧情留待二期。

## 四、KPI 功过簿制度

### 1. 月度考核

- **周期**：三十日一考（`MONTH_DAYS = 30`，沿用旧制）。
- **功过目标公式**（沿用母本/旧代码基准）：

```
monthTarget(month) = 50 + month × 15
```

### 2. 前 12 月目标递增建议表

| 考核月 | 目标功过值 | 所处章节（建议节奏） |
|---|---|---|
| 第1月 | 65 | 章1（转正月，双条件之一） |
| 第2月 | 80 | 章1末~章2初 |
| 第3月 | 95 | 章2 |
| 第4月 | 110 | 章2末（巡按晋升参考线） |
| 第5月 | 125 | 章3初 |
| 第6月 | 140 | 章3（枉死城长单高峰） |
| 第7月 | 155 | 章3末（主簿月） |
| 第8月 | 170 | 章4初 |
| 第9月 | 185 | 章4（削藩外勤） |
| 第10月 | 200 | 章4末（判官月，末考） |
| 第11月 | 215 | 章5初（四凶/刑天高压） |
| 第12月 | 230 | 章5（终章月，目标只作结算演出，结局判定优先） |

- 第12月以后二期继续按公式线性增长（每月 +15），如第18月=320；也可在二期改为分段函数，本册不锁死。
- **功过值来源**：工单结算 merit 全额计入；额外加减：
  - 超度/放生/拒贿/完整证据链：+3~+8（魏征赏善司核销）；
  - 贪墨、冤杀可和解妖、硬吞妖丹被察觉：−5~−15（陆之道察查司记档）；
  - 官遣单失败：−10 起步。

### 3. 考核评级与惩罚

| 月绩 | 评级 | 后果 |
|---|---|---|
| ≥ 目标 120% | 上考（卓异） | 香火钱奖、阎罗点名、下月好工单优先派 |
| 目标 100%~120% | 称职 | 正常 |
| 目标 70%~99% | 下考（疲软） | 无奖，崔珏处喝茶剧情，工单池质量下降一档 |
| ＜目标 70% | **不称职** | 记过一次，罚当月香火钱；工单架容量临时 −1 |

- **连续两次「不称职」：贬作孤魂野鬼，永不叙用。**（母本规定，等于游戏失败结算）
  - 结算演出：劳务契当场焚化，腰牌收回，玩家魂魄被两个鬼差请出枉死城，飘向夹壁——镜头可与章2野庙土地公散纸灰一幕互文。
  - 给玩家的缓冲：第一次不称职后，崔珏会派一张低难度「送分长单」（人情债，好感足够才给）；连续两次之间也保留读档。
