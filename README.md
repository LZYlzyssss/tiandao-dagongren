# 天道打工人

> 一个外包阴神的升职(？)之路 · 2D 水墨国风修仙网页游戏

## 一句话概念

你在天庭体制边缘挂职，替东西方各路神佛大佬处理脏活累活；他们付不起工钱，只能切一块**神格**给你——神格攒多了，你会概率觉醒神通，也在不知不觉中走上一条谁也没见过的修行路。

## 快速开始

### 方式一：双击打开（最简单）
直接双击 `index.html` 即可在浏览器中游玩。

### 方式二：本地服务器（推荐，手机也能玩）
```bash
# 在项目根目录执行
node -e "const http=require('http'),fs=require('fs'),p=require('path');const t={'.html':'text/html;charset=utf-8','.js':'text/javascript;charset=utf-8','.css':'text/css'};http.createServer((q,s)=>{let f=p.join(process.cwd(),decodeURIComponent(q.url.split('?')[0]));if(q.url==='/')f=p.join(process.cwd(),'index.html');fs.readFile(f,(e,d)=>{if(e){s.writeHead(404);s.end('404')}else{s.writeHead(200,{'Content-Type':t[p.extname(f)]||'application/octet-stream'});s.end(d)}})}).listen(8770)"
```
- 电脑浏览器：http://localhost:8770/
- 手机浏览器（同 WiFi）：http://192.168.x.x:8770/（用 `ipconfig` 查看你的 IPv4 地址）

> 若手机打不开，可能是 Windows 防火墙拦截，以管理员身份执行：
> ```
> netsh advfirewall firewall add rule name="TiandaoGame" dir=in action=allow protocol=TCP localport=8770
> ```

## 核心玩法

### 游戏循环（约 15 分钟一局体验）

```
坐衙接案 → 审卷议价 → 下凡执行（事件抉择 → 简化战斗）→ 结算（神格/修为/香火钱）→ 经营神衙 → 月末 KPI 考核晋升
```

### 1. 坐衙审批

- 案几每天刷出 2–4 张工单，列明委托神、案情、危险等级、报酬
- 可**接案** / **驳回**（得罪人）/ **讨价还价**（耗 1 人情，香火钱 +50%）
- 阎王的**官遣单**红框标记，不可驳回

### 2. 下凡执行

- 每张工单是 3–5 个剧情节点的短途旅程
- 每节点 2–3 个选项，选项受已镶嵌神格影响
  - 持有火德神格可选「火攻」
  - 持有佛门神格可选「以佛理折服」
  - 持有幽冥神格可选「调幽冥律令」

### 3. 简化战斗

- **自动进行**：双方按攻击/防御/神力自动对撞，约 8–12 回合
- 血条、飘字（"铛！""-37"）、水墨挥砍特效
- **全场 2 个关键时刻**（敌人血量降至 60%、30% 时触发），四选一：
  - **祭法宝**：消耗神力，释放已觉醒神格的大招
  - **拼命**：透支一枚神格换毁灭性爆发，该神格沉睡 3 日
  - **凝神接战**：不做特殊操作，继续自动对撞
  - **遁走**：保命撤退，委托按失败结算

### 4. 神格系统（核心卖点）

| 机制 | 说明 |
|------|------|
| **获取** | 完成委托必得对应神明的神格碎片，整块神格自动入体 |
| **双重收益** | 每枚神格固定提供基础修为加成；获取时按觉醒率概率觉醒一个专有技能 |
| **觉醒率** | 基础 30%，升级神龛可提升至 45%/60% |
| **参悟** | 未觉醒的神格可花费 120 香火钱在神格盘手动参悟，提升觉醒率 |
| **道途分类** | 战、佛、天启、幽冥、火德，共 5 种道途 |
| **同道共鸣** | 同道途两枚及以上神格同时镶嵌，攻击 +10% |
| **道争** | 天启 ⟷ 幽冥 不可轻同修，同时镶嵌时神力上限 −20% |
| **融合神格** | 特定两枚神格双双觉醒后，可在神格盘投入香火钱尝试融合 |

### 6. 月末 KPI 考核

- 游戏内每 30 天，阎王审你功过簿
- **功过目标**：第 1 月 50 点，之后每月 +15
- **称职**：品阶晋升（九品阴神 → 从八品 → 八品 → 从七品判官 → 七品判官），镶嵌槽 +1，赏 80 文
- **不称职**：记大过一次
- **连续两次不称职**：贬为孤魂野鬼，Game Over

## 世界观

天庭机构臃肿、预算紧缩，正式神仙只管显灵不管干活，杂务全部外包。你签的是「阴阳两界劳务契」，没有编制。

世界观天然容纳万神：斗战胜佛孙悟空、天使长米迦勒、三坛海会大神哪吒都是你的甲方；顶头上司是地府阎王（只给 KPI 不给好脸色）。

文案基调：**七分正经三分皮**——世界观和神话考据是正经的，神仙有气场；但界面文案、工单细节充满打工人梗（KPI 考核、香火钱报销、悟空投诉文书），反差出笑点。

## 扩展指南

### 添加新神明

在 `js/data.js` 中追加三项：

```javascript
// 1. 神明
GODS.donghai = { name:'东海龙王', title:'敖广', icon:'龙', img:'...' };

// 2. 神格
GODHOODS.haishen = { name:'海神', god:'donghai', path:'war', icon:'海',
  desc:'...', cult:30, stat:{hp:15,atk:5},
  passive:{crit:0.1, label:'暴击率+10%'},
  active:{name:'怒涛', cost:25, type:'burn', mult:1.2, burnRounds:3, burnPct:0.4, desc:'...'} };

// 3. 工单
MISSIONS.push({ id:'m9', god:'donghai', danger:3, forced:false,
  name:'东海夜潮', gh:'haishen', merit:18, money:100, scroll:'...',
  nodes:[ {type:'event',...}, {type:'battle',enemy:'...'}, ... ] });
```

战斗引擎、经营层、UI 自动适配，无需改动其他文件。

### 添加新敌人

在 `js/data.js` 的 `ENEMIES` 中追加：
```javascript
ENEMIES.seamonster = { name:'海兽', icon:'兽', tint:'#1a5a7a', hp:180, atk:25, def:7 };
```

### 添加新法宝/阴兵

在 `js/data.js` 的 `ITEMS` / `SOLDIERS` 中追加即可。

### 添加新融合配方

在 `js/data.js` 的 `FUSIONS` 中追加：
```javascript
{ out:'newFusion', in:['godhoodA','godhoodB'], cost:500, baseRate:0.5 }
```
并在 `GODHOODS` 中定义融合产物。
